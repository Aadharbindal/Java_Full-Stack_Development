## Reading order

Numbered in teaching order. Two things worth knowing before you start:

**Files 01 and 02 are the same class.** File 01 is the polished writeup (9 pages, fuller prose); file 02 is the raw OneNote capture from the session (6 pages). Read 01 for the detail, 02 for the quick version.

**File 06 is a subset of file 05.** Both are the 14 June control-statements session with the same title and timestamp. File 05 runs to 6 pages and continues into the introduction to loops; file 06 stops after `switch` at 3 pages, and its text appears in full inside file 05. Read 05 — file 06 is kept only so nothing from the original drop is lost.
