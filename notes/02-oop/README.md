## Reading order

Numbered in teaching order, which is also the sensible reading order — classes and objects first, then constructors to initialise them, then the principles, then variable scope and interfaces.

**File 04 is not a class session.** It is a written reference titled "OOPs Notes — Part 2", undated and the longest document here at 19 pages. It covers the same principles as file 03 but in much more depth, with comparison tables and full code listings, and it is phrased in the style of interview questions. Use file 03 for the class explanation and file 04 for revision and depth.

One difference worth noticing between the two: file 03 lists **four** principles (inheritance, encapsulation, polymorphism, abstraction), while file 04 argues for **three**, treating abstraction as a concept used across the other three rather than a principle of its own. Both framings are common; the four-principle version is the one taught in class.
