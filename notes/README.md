# Notes

Class notes (PDF) from the Java Full Stack Development course, organised by topic in the order they were taught.

The [code](../01-core-java) folders hold the programs written in class; these notes hold the theory behind them.

## Structure

```
notes/
├── 01-java-basics/          Introduction, variables, operators, control statements, arrays
├── 02-oop/                  Classes, objects, methods, constructors, OOP principles, interfaces
└── 03-exception-handling/   Exceptions, try-catch-finally, throw and throws
```

Section numbers group topics rather than dates. Class dates are listed in every table below, so the actual teaching order stays visible even where a topic was taught out of sequence.

## Conventions

- Files are numbered in teaching order within each folder, so the listing matches the course flow.
- Names are lowercase and hyphenated, describing the topic rather than the original export filename.
- Original filenames were things like `Class 1 - Introduction To Java Redesigned.pdf`; they have been renamed for consistency. Content is untouched.
